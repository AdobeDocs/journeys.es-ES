# round {#round}

Devuelve el valor entero más cercano al argumento con vínculos de redondeo al infinito positivo.

## Categoría

Matemáticas

## Sintaxis de función

`round(<parameters>)`

## Parámetros

* decimal
* entero

## Firmas y tipo devuelto

`round(<decimal>)`

`round(<integer>)`

Devuelve un entero.

## Ejemplo

`round(3.14)`

Devuelve 3.

`round(3.54)`

Devuelve 4.

`round(-3.14)`

Devuelve -3.

`round(3)`

Devuelve 3.
