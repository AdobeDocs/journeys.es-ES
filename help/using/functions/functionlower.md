# lower {#lower}

Devuelve una versión en minúsculas del parámetro.

## Categoría

Cadena

## Sintaxis de función

`lower(<parameter>)`

## Parámetro

* cadena

## Firma y tipo devuelto

`lower(<string>)`

Devuelve una cadena.

## Ejemplo

`lower("A")`

Devuelve &quot;a&quot;.
